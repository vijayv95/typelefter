# typelefter
TypeLefter is a minimalist, project-based writing tool built for authors who love the simplicity of Markdown and the organizational power of a binder structure. It provides a clean and focused environment to write, while ensuring your project files are neatly organized and easy to navigate. Typelefter is built with Python, C++ and PySide6 (Qt).

## Vision

TypeLefter is an open-source writing environment for creating and managing long-form content.

Built on the principles of openness, transparency, and user ownership, TypeLefter aims to provide powerful tools for planning, organizing, and writing without locking users into proprietary formats. Writers remain in control of their work, with projects designed to be accessible both inside and outside the application.

While inspired by established writing tools, TypeLefter is evolving its own workflow and philosophy, guided by a commitment to open standards and long-term accessibility.

For the complete vision and guiding principles, see [`docs/01-product-vision.md`](docs/01-product-vision.md).
